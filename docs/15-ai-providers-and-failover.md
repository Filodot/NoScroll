# AI-провайдеры и отказоустойчивость

## Выбранные варианты

1. **Google Gemini** — основной. Модель по умолчанию `gemini-3.6-flash`, у Gemini Developer
   API есть ограниченный бесплатный tier:
   [pricing](https://ai.google.dev/gemini-api/docs/pricing),
   [models](https://ai.google.dev/gemini-api/docs/models).
2. **Groq** — первый резерв. Модель `openai/gpt-oss-20b` поддерживает строгий JSON Schema:
   [structured outputs](https://console.groq.com/docs/structured-outputs),
   [rate limits](https://console.groq.com/docs/rate-limits).
3. **OpenRouter** — второй резерв. `openrouter/free` выбирает доступную бесплатную модель.
   Без купленных кредитов бесплатный лимит обычно составляет 50 запросов в сутки:
   [FAQ](https://openrouter.ai/docs/faq),
   [free models](https://openrouter.ai/docs/guides/routing/model-variants/free).

Бесплатность и лимиты определяет провайдер, поэтому приложение не обещает вечный бесплатный
доступ. Модель каждого адаптера редактируется без выпуска нового APK.

## Порядок вызова

`Gemini → Groq → OpenRouter`

- Пропускаются выключенные сервисы и сервисы без ключа.
- Ошибка одного провайдера не теряет локальный курс: запрос передаётся следующему.
- После двух временных сбоев circuit breaker исключает провайдера на 10 минут.
- Ошибки авторизации и некорректные запросы не маскируются бесконечными повторами.
- Ответ каждого адаптера приводится к единому объекту с ID фактической модели и временем.

## Структурированный ответ

Gemini получает `responseMimeType=application/json` и JSON Schema. Groq и OpenRouter получают
OpenAI-совместимый `response_format=json_schema`; для OpenRouter дополнительно включён
`require_parameters`, чтобы роутер не выбрал модель без поддержки схемы. Даже после этого
ответ повторно разбирается и проверяется самим NoScroll — провайдер не является доверенной
границей.

## Ключи и приватность

- API-ключ вводит пользователь; ключей в APK и Git нет.
- Значение шифруется AES-GCM ключом из Android Keystore.
- Обычное состояние UI содержит только `hasApiKey`; сохранённый секрет назад в поле не выводится.
- `allowBackup=false`, поэтому зашифрованные данные не переносятся в облачную копию.
- В сетевой запрос одного провайдера никогда не попадает ключ другого.
- Разрешён только HTTPS; cleartext-трафик запрещён манифестом.

При генерации материал курса будет передаваться выбранному внешнему провайдеру. Интерфейс должен
сообщать об этом до первого запроса. Исходный файл целиком не отправляется: генератор выбирает
ограниченные локальные фрагменты.
