# Безопасные Python и SQL-задания (EDU-10)

## Граница реализации

NoScroll не запускает произвольный Python и не добавляет тяжёлый нативный runtime. Для первых
учебных задач реализован ограниченный интерпретатор выражений. SQL выполняется штатной SQLite в
новой in-memory базе для каждого теста.

Code-задачи доступны в полном экране урока и не используются как gate до отвлекающего приложения.
Так ошибка sandbox или слишком сложное решение не может заблокировать доступ.

## Python subset

Ответ должен содержать одно объявление `def` и одну строку `return`. Поддерживаются:

- аргументы scalar из JSON object/array;
- числа, строки и boolean;
- `+`, `-`, `*`, `/`, `//`, `%`, `**`;
- `==`, `!=`, `<`, `<=`, `>`, `>=`;
- `and`, `or`, `not`;
- `len`, `abs`, `round`;
- скобки и унарные операторы.

Отключены imports, loops, classes, lambda, async, exceptions, attributes, dunder, reflection,
filesystem, network и Android API. Ограничены длина кода, параметры, токены, строки, тесты и
размер результата.

Это осознанно не полный Python. Генератор получает точный контракт subset и не должен создавать
задачу, которой требуется неподдержанный синтаксис.

## SQL sandbox

Каждый тест:

1. создаёт новую `SQLiteDatabase.create(null)`;
2. применяет только setup-команды `CREATE TABLE` и `INSERT INTO`;
3. выполняет один пользовательский `SELECT` или `WITH … SELECT`;
4. ограничивает число строк, колонок и размер результата;
5. закрывает базу.

Запрещены `ATTACH`, `PRAGMA`, DML/DDL пользователя, triggers, recursive CTE, extension loading,
большие blob-функции и несколько выражений.

Канонический результат: строки разделены `\n`, колонки — `|`, SQL NULL записывается как `NULL`.

## Тесты и UX

- У задания должно быть минимум два теста: открытый и скрытый.
- Открытые input/output показываются перед редактором.
- Скрытые значения никогда не раскрываются в сообщении об ошибке.
- Ошибка синтаксиса не меняет mastery; неверный выполненный результат записывается как попытка.
- Правильный результат проходит обычный `MasteryPolicy`.
- Клавиатура получает `imePadding`, поэтому редактор и кнопка остаются доступны.

## Ограничения

Задачи, которым нужен полный Python, библиотеки, состояние между вызовами или изменение SQL-базы,
должны генерироваться как `CODE_OUTPUT`/`CODE_COMPLETION` либо заменяться пользователем.
`TEACH_BACK` остаётся вне автоматической генерации до появления надёжной рубрикаторной проверки.
