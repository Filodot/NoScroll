# Исправление накопления сложности (0.9.1)

## Причина

Активность YouTube Shorts измеряется монотонными системными часами Android. Периодический
heartbeat может прийти немного раньше полной секунды, например через 999 мс. Предыдущая версия
округляла прошедшее настенное время вниз до нуля и отбрасывала уже подтверждённую мониторингом
секунду просмотра. При повторении этого сценария шкала сложности росла слишком медленно либо
визуально не росла вовсе.

## Новая логика

- подтверждённые активные секунды из `elapsedRealtime` больше не ограничиваются округлённым
  настенным интервалом;
- перерыв по-прежнему вычисляется по настенным часам и не может стать отрицательным;
- перевод часов назад не меняет накопленную нагрузку;
- накопление и плавный спад остаются независимыми от типа создаваемого задания.

Регрессионные тесты проверяют единичный heartbeat на 900 мс, серию из 60 ранних heartbeat и
совместную обработку длительного перерыва с новой активной секундой.
