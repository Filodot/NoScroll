# Умные уроки — release 0.8

## Границы релиза

Версия `0.8.2` хранит курсы, материалы, планы, уроки, попытки и прогресс на устройстве.
Аккаунт и backend NoScroll не нужны. Сеть используется только после явного нажатия генерации;
gate никогда не ждёт AI и выдаёт лишь заранее проверенное локальное задание либо безопасный
арифметический fallback.

## Реализованный путь пользователя

1. Создать курс по теме либо импортировать PDF, DOCX, TXT или Markdown до 20 МБ.
2. Подключить один или несколько собственных API-ключей.
3. Сгенерировать проверяемый план, отредактировать порядок и содержание тем, подтвердить его.
4. Сгенерировать следующий урок с мини-статьёй; некорректный JSON или низкое качество автоматически
   отклоняются и запрашиваются повторно.
5. Сначала изучить мини-статью, затем пройти связанные с ней задания на понимание.
6. Проходить уроки офлайн с постепенным продвижением и интервальным повторением.
7. При желании включить готовые учебные задания в gate YouTube/Instagram: статья также будет
   показана раньше вопроса.
8. Удалить курс вместе с извлечённым текстом, планом, уроками, попытками и mastery.

## Форматы заданий

Модель данных поддерживает single/multiple choice, true/false, fill blank, numeric/short answer,
ordering, matching, scenario, evidence selection, flashcard, code output, code completion,
code fix, mini-code и teach-back. Автоматический генератор использует только форматы, которые
приложение способно объективно проверить; в gate выдаётся задание с одним однозначным правильным
ответом.

Python-упражнения исполняются не как настоящий Python, а в ограниченном expression subset без
импортов, циклов, атрибутов, файлов, сети и Android API. SQL выполняется в новой in-memory SQLite
базе для каждого запуска; разрешены только `SELECT`/`WITH ... SELECT`, а setup и тесты задаются
проверенным пакетом урока.

## Провайдеры и отказоустойчивость

Порядок по умолчанию:

1. Gemini `gemini-3.6-flash`;
2. Groq `openai/gpt-oss-20b`;
3. OpenRouter `openrouter/free`.

Идентификаторы и бесплатные tiers повторно сверены по официальной документации 24 июля 2026 года.
Пользователь может изменить model ID без обновления APK. Отсутствующий ключ пропускается, временно
сломанный провайдер после повторных ошибок исключается на 10 минут, а запрос переходит к следующему.
После ответа NoScroll самостоятельно проверяет схему, содержание, ссылки на источник и quality
score. Генерация делает до трёх попыток с обратной связью о причине отклонения.

Бесплатность не гарантируется приложением: квоты и условия определяет каждый сервис. При исчерпании
квоты локальные курсы и ранее созданные уроки продолжают работать.

## Надёжность

- Room schema 9 обновляется только явными миграциями без destructive fallback.
- Pending gate, допуски, уроки и прогресс переживают перезапуск процесса и телефона.
- Долгие AI/import операции корректно отменяются и не обновляют закрытый экран старым результатом.
- Failover-состояние потокобезопасно; одна параллельная генерация не повреждает circuit breaker другой.
- Файлы читаются потоково с лимитом, PDF ограничен 500 страницами, DOCX XML — 8 МБ,
  извлечённый текст курса — 2 млн символов.
- Повреждённый, пустой, защищённый паролем или неподдерживаемый материал получает понятную ошибку
  без частично сохранённого курса.
- Экран задания использует `imePadding`, поэтому клавиатура не скрывает условие и кнопку проверки.

## Приватность

- Содержимое YouTube/Instagram не сохраняется и не отправляется провайдерам.
- Ключи отсутствуют в исходниках и APK, хранятся в виде AES-GCM ciphertext; ключ шифрования
  создаётся Android Keystore.
- Backup и device transfer для app-private данных отключены.
- AI-запрос содержит только ограниченные выбранные фрагменты материала и отправляется выбранному
  внешнему провайдеру по HTTPS.
- Cleartext traffic, `QUERY_ALL_PACKAGES`, overlay и storage/media permissions отсутствуют.

## Release gate

Перед выдачей APK выполняются unit/Robolectric тесты, Android/Compose lint с
`warningsAsErrors=true`, сборка debug/release и компиляция instrumentation-тестов. Release APK
проверяется `apksigner`, а SHA-256 фиксируется при выдаче.

Локальная release-сборка подписана тем же debug-сертификатом, что и предыдущие тестовые APK:
это позволяет установить `0.8.2` поверх них. Для Google Play этот ключ не используется —
публикация должна перейти на отдельный production upload key и Play App Signing.

Автоматические проверки не заменяют device smoke-test Accessibility/Usage Access на конкретной
прошивке Samsung/Xiaomi/Pixel. До публичного релиза вручную проверяются перезагрузка, сутки работы,
YouTube Shorts, Instagram, Emergency Stop, крупный шрифт, офлайн и отзыв системных разрешений.
