# Генерация и редактирование программы

## Вход генератора

Курс по теме передаёт формулировку пользователя и явно требует пустые ссылки на источники.
Курс по материалу передаёт не весь файл, а до 12 репрезентативных фрагментов: начало, равномерно
распределённая середина и конец. Один фрагмент ограничен 2 400 символами.

Материал помещается в отдельные XML-подобные границы и объявляется недоверенными данными.
Системный prompt запрещает выполнять инструкции из файла — это снижает риск prompt injection.

## Формат плана

Ответ содержит:

- предложенные название и описание;
- 2–20 последовательных тем;
- длительность и измеримый результат каждой темы;
- 1–8 понятий на тему;
- зависимости только от ранее введённых понятий;
- ID реальных фрагментов-источников для каждого факта курса по материалу.

ID доменных объектов создаёт само приложение. Модель не управляет первичными ключами Room.

## Quality gate

NoScroll независимо проверяет:

- точный набор JSON-полей;
- границы строк, количества тем, понятий и длительности;
- отсутствие повторяющихся понятий;
- корректный порядок prerequisites;
- отсутствие выдуманных `chunkId`;
- обязательную привязку каждого понятия к материалу;
- отсутствие фиктивных цитат у курса только по теме.

Порог принятия — 85/100. Некорректный результат не сохраняется: замечания добавляются в следующий
запрос, всего разрешено до трёх попыток. После исчерпания попыток локальный курс остаётся
неизменным.

## Редактор и подтверждение

Принятый результат сохраняется как `DRAFT`. Пользователь может:

- переписать название и результат темы;
- изменить порядок;
- удалить или добавить тему;
- перегенерировать весь план;
- явно подтвердить финальную структуру.

Поля обновляются на экране сразу, а запись в Room выполняется с debounce 500 мс, чтобы набор текста
не создавал очередь транзакций. Подтверждение отменяет ожидающую запись, сохраняет актуальное
состояние, увеличивает `planVersion` и переводит курс в `READY`. Только подтверждённый план может
использоваться генератором уроков.
