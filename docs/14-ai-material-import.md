# Импорт учебных материалов

## Поддерживаемые входы

- тема, введённая пользователем;
- PDF с текстовым слоем;
- DOCX;
- TXT в UTF-8 (BOM допускается);
- Markdown.

Системный `OpenDocument` выдаёт доступ только к выбранному файлу. NoScroll не запрашивает
разрешение на просмотр всего хранилища и сразу сохраняет извлечённый текст в своей Room-базе.

## Локальный конвейер

1. Проверка MIME-типа, расширения и размера файла.
2. Извлечение текста на `Dispatchers.IO`.
3. Нормализация переносов и лишних пробелов.
4. Ограничение итогового текста.
5. SHA-256 для обнаружения одинакового содержимого.
6. Разбиение по абзацам и предложениям на ограниченные фрагменты.
7. Сохранение фрагментов с позицией, страницей/разделом и примерной стоимостью в токенах.

Фрагменты являются единственной копией содержимого, необходимой будущему генератору. Исходный
файл не копируется, поэтому приложение не удерживает лишние десятки мегабайт и не зависит от
того, останется ли URI доступным после перезапуска.

## Ограничения прототипа

| Параметр | Значение |
|---|---:|
| Размер исходного файла | 20 МБ |
| Страниц PDF | 500 |
| Распакованный `word/document.xml` | 8 МБ |
| Нормализованный текст | 2 000 000 символов |
| Целевой фрагмент | 2 200 символов |
| Жёсткий максимум фрагмента | 3 200 символов |

PDF без текстового слоя (сканы) может импортироваться как пустой. В этом случае пользователь
получает явную ошибку; OCR намеренно не запускается в фоне, чтобы не перегревать телефон.
PDF с паролем отклоняется. Для обычных PDF используется локальный PDFBox; необязательные
криптографические зависимости исключены из APK.

## Grounding

- Курс из файла получает `SOURCE_REQUIRED`: фактические задания должны ссылаться на сохранённые
  фрагменты.
- Курс только по теме получает `AI_KNOWLEDGE`: интерфейс всегда предупреждает, что проверяемого
  источника нет.

После импорта курс остаётся в статусе `DRAFT`. Следующий пакет работ строит редактируемый план,
проверяет качество ответа модели и только затем переводит курс в `READY`.
