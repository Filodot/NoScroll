# Лексика, ежедневная статистика и общая нагрузка (0.11.0)

## Английские слова B1–C1

Добавлен полностью офлайн-тип задания `ENGLISH_VOCABULARY`. Он не использует AI и доступен в
разделе «Задания» наравне с арифметикой, движением, пользовательскими пресетами и умными уроками.

Каждая пауза состоит из двух последовательных экранов:

1. четыре английских слова со значениями на русском и короткими примерами;
2. один вопрос с единственным правильным вариантом по только что показанному списку.

Уровень слов определяется общей сложностью задания: лёгкая — B1, средняя — B2, сложная — C1.
Направление вопроса чередуется: выбрать значение английского слова или восстановить слово по
русскому значению. Встроенный каталог содержит независимые наборы каждого уровня и циклически
покрывается без сетевого запроса.

## Ежедневная статистика

Экран «Сегодня» показывает:

- суммарное время YouTube, Instagram, Pinterest и Chrome за текущий день;
- отдельный вклад каждого приложения и время Shorts внутри YouTube;
- компактную историю последних семи календарных дней;
- изменение среднего времени последних завершённых дней относительно предыдущего периода.

Shorts являются подмножеством YouTube и никогда не прибавляются к общему времени повторно.
Если данных ещё недостаточно, интерфейс не заявляет об улучшении и показывает состояние сбора
базы. Для тренда требуется минимум по два наблюдаемых дня в каждом из сравниваемых периодов.
Локальные дневные строки хранятся 90 дней и не отправляются с устройства.

При выданном Usage Access NoScroll периодически восстанавливает активное время всех четырёх
поддерживаемых пакетов из системных событий Android. Неизвестные имена пакетов по-прежнему
нормализуются в обезличенное событие и не сохраняются в статистике.

## Общая шкала сложности

В долговечную шкалу нагрузки теперь входит активное время любого контролируемого приложения:

- YouTube целиком, включая Shorts, но без двойного счёта;
- Instagram;
- Pinterest;
- Chrome.

Одновременно может быть активно только одно foreground-приложение, поэтому один интервал времени
добавляется в шкалу ровно один раз. Включён ли интервальный gate конкретного приложения, на
статистический учёт и нагрузку не влияет. Во время отсутствия во всех этих приложениях шкала
плавно восстанавливается согласно пользовательской настройке.

## Надёжность и совместимость

- Новая статистика использует существующую таблицу `daily_usage`; миграция базы не требуется.
- Новый тип задания хранится в уже существующем текстовом поле pending task и безопасно читается
  версиями 0.11+.
- История публикуется реактивно после каждого сохранения: репозиторий держит последние 15 строк
  для сравнения двух периодов, UI показывает семь дней, а локальная политика хранения оставляет
  до 90 дней для будущей аналитики.
- Неизвестные или удалённые типы настроек продолжают восстанавливаться к безопасным значениям.
