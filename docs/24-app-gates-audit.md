# Ограничения приложений и аудит runtime (0.10.0)

## Цели

Помимо отдельного детектора YouTube Shorts, NoScroll поддерживает интервальные задания для всего
нативного YouTube, Instagram, Pinterest и Chrome. У каждой цели собственные включение, интервал,
счётчик активного времени, входной cooldown и сохранённое состояние. Pinterest и Chrome также
добавлены в каталог полного фокус-блока.

Новые ограничения всего YouTube, Pinterest и Chrome выключены по умолчанию. Это защищает
существующих пользователей от внезапной блокировки после обновления. Рекомендации: YouTube — 15,
Pinterest — 10, Chrome — 20 минут.

## Порядок правил

1. Emergency Stop и активный фокус-режим имеют наивысший приоритет.
2. Суточный лимит всего YouTube не может быть продлён заданием.
3. Для YouTube проверяется общий входной/интервальный gate.
4. Внутри Shorts дополнительно действует отдельная политика Shorts с мягкой остановкой на свайпе.
5. Для Instagram, Pinterest и Chrome проверяется их независимый gate.

Правильный ответ сбрасывает только счётчик целевого приложения. Cooldown равен выбранному
интервалу и сохраняется в Room, поэтому перезапуск процесса не требует повторной платы за вход.

## Найденные и устранённые риски

- Pinterest и Chrome добавлены в Android `<queries>`, иначе Android 11+ мог запретить запуск после
  решения задания.
- Снимок accessibility-дерева запрашивается только для YouTube; остальные приложения передают
  только пакет, тип события и системное время.
- Добавлена миграция Room `9 → 10` без потери старых счётчиков, pending task и учебных данных.
- Транзакция выдачи доступа атомарно обновляет нужный счётчик и не затрагивает остальные цели.
- Выключенные gates не накапливают интервальный долг, но дневная статистика продолжает считаться.
- Устаревшая версия схемы настроек повышается до текущей при чтении.

## Автоматические проверки

Покрыты: чистая политика входа/интервала/cooldown, все четыре accessibility-пакета, отсутствие
снимков экрана для не-YouTube целей, миграция базы, round-trip настроек, атомарные grants для
YouTube/Pinterest/Chrome, каталог фокус-режима, нормализация интервалов и состояния dashboard.
